== Requisitos Globales del Sistema

Esta seccion define los requisitos generales de Figuras Que Ensenan como sistema completo. No describe todavia los requisitos particulares de cada microservicio, sino las capacidades y cualidades que debe cumplir la plataforma considerando todos sus componentes: clientes, gateway, servicios backend, deteccion de manos, bases de datos, mensajeria, logs y modulo administrativo.

=== Reglas de Negocio Globales

* El estudiante solo puede consultar y modificar informacion asociada a su propio identificador.
* El tutor solo puede consultar informacion de estudiantes que esten asociados a su cuenta.
* El tutor solo puede consultar sesiones y resultados de estudiantes asignados.
* Las funciones administrativas requieren rol de administrador.
* El acceso a datos se controla mediante tokens JWT y validacion de rol.
