== Pruebas de Estres con JMeter

Para complementar las pruebas funcionales con Newman, se ejecuto una prueba de estres sobre el gateway del sistema utilizando Apache JMeter. La ejecucion se realizo contra el gateway expuesto en `http://localhost:3000`, con una mezcla de solicitudes publicas y protegidas para aproximarse a un escenario de uso real.

[cols="2,3", options="header"]
|===
|Configuracion |Valor aplicado

|Herramienta
|Apache JMeter 5.6.3

|Fecha de ejecucion
|27 de mayo de 2026, 00:39 (America/Mexico_City)

|Usuarios concurrentes
|46

|Ramp-up
|15 segundos

|Loops por usuario
|10

|Solicitudes esperadas por iteracion
|5
|===

La mezcla de trafico enviada al gateway incluyo los siguientes endpoints:

[cols="2,4", options="header"]
|===
|Endpoint |Objetivo

|`GET /health`
|Validar disponibilidad general del gateway.

|`GET /openapi.json`
|Verificar exposicion del contrato OpenAPI.

|`POST /auth/login`
|Medir el costo de autenticacion y generacion de JWT.

|`GET /data/students`
|Probar el paso hacia un endpoint protegido usando token JWT.

|`GET /logs/api/logs?limit=2`
|Validar el enrutamiento hacia el servicio de logs.
|===
